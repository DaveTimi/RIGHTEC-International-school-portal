# Levity Ethics Systems — Database Seed Data

This directory contains development and test seed data for
Levity Ethics Systems.

Seed data is used to create safe sample records during
development and testing.

## Important

Production schools, users, students, staff, financial records,
and other real data must NOT be placed in seed files.

Never store:

- passwords
- API keys
- authentication secrets
- payment secrets
- private tokens
- real student information
- real staff information

Production data will be created through the application's
authenticated administrative workflows.

## Planned seed data

Development seeds may eventually include:

- One sample school
- Sample administrative user
- Sample staff
- Sample students
- Sample classes
- Sample subjects
- Sample academic session
- Sample academic terms

All sample records must clearly be development/test data.
